# Site institucional — Assembleia de Deus Canal Meriti

## Objetivo

Criar um site institucional para apresentar a Assembleia de Deus — Canal Meriti, disponibilizando informações sobre a igreja, seus encontros, horários, localização e canais de comunicação.

O site tem como objetivo facilitar o acesso às informações para membros, visitantes e pessoas interessadas em conhecer a igreja.

## Problemas Identificados

- A igreja não possui um site institucional para centralizar suas informações.
- Pessoas interessadas podem ter dificuldade para encontrar informações sobre os cultos e horários.
- Não existe um canal centralizado para apresentar a localização da igreja.
- É necessário facilitar o acesso às redes sociais da igreja.
- Visitantes precisam de informações claras sobre os dias e horários dos encontros.
- A localização física da igreja precisa ser apresentada de forma simples e acessível.

# Levantamento de Requisitos

## Requisitos Funcionais

- O site deve apresentar o nome e a identidade visual da igreja.
- O site deve apresentar uma mensagem de boas-vindas aos visitantes.
- O site deve disponibilizar um link para o Instagram oficial da igreja.
- O site deve apresentar os encontros realizados pela igreja.
- O site deve apresentar os dias dos cultos.
- O site deve apresentar o tipo de cada encontro.
- O site deve apresentar os horários dos cultos.
- O site deve apresentar o endereço da igreja.
- O site deve disponibilizar um mapa com a localização da igreja.
- O site deve apresentar informações de contato e localização de forma acessível.
- O site deve apresentar os créditos de desenvolvimento no rodapé.

## Requisitos Não Funcionais

- O site deve funcionar em celulares, tablets e computadores.
- O site deve possuir uma interface organizada e visualmente agradável.
- Os textos devem possuir boa legibilidade.
- Os elementos da página devem possuir espaçamento adequado.
- O site deve utilizar uma estrutura visual consistente.
- O site deve possuir adaptação para telas maiores por meio de Media Queries.
- Os links devem possuir indicação visual adequada para interação do usuário.
- As imagens devem possuir textos alternativos (`alt`) para melhorar a acessibilidade.


## Regras de Negócio

- Os dias e horários apresentados devem corresponder aos encontros oficiais da igreja.
- As informações apresentadas no site devem ser informações oficiais da Assembleia de Deus — Canal Meriti.
- O endereço apresentado deve corresponder à localização oficial da igreja.
- O mapa deve indicar a localização correta da igreja.
- O link disponibilizado para o Instagram deve direcionar para o perfil oficial da igreja.
- Cada encontro deve apresentar seu respectivo dia, atividade e horário.
- As informações de localização devem permanecer atualizadas para evitar que visitantes sejam direcionados para um local incorreto.
